# 字相 · Glyph Studio 1.3.0

1.3.0 为 Windows x64 便携版加入启动检查和经过校验的内置更新流程，同时保留本地图像处理和本机设置。

## 亮点

- 每次启动自动查询 GitHub 最新稳定版本元数据。右下角显示“自动检查更新…”，“已是最新版”或“检查失败点击重试”。
- 检测到新版本时，右下角显示红点和“检测到更新，点击更新”。点击后先确认“更新并重启”，并提醒先导出当前作品。
- 确认后从 GitHub Release 下载对应的官方 Windows x64 便携版 EXE 到当前程序目录，显示下载进度并提供取消下载按钮，然后在替换前核对发布的 SHA-256 和文件大小。
- 程序退出后由隐藏的 Windows 更新助手等待文件解锁，保留旧文件备份，替换为官方版本文件名并重启。只有新版本完成启动握手后才删除备份；下载、校验、替换或启动失败时保留或恢复旧版本。
- 取消下载、只读目录、网络中断、下载不完整、缺少摘要或校验失败会显示中文错误并保留旧版本，不请求管理员权限。

## 数据和迁移

图片解码、转换和导出仍在本机完成。启动检查只向 `api.github.com` 读取版本元数据；确认更新后才访问 GitHub Release 或 `release-assets.githubusercontent.com` 下载官方资产。请求不包含图片、账号或其他应用数据。

更新会保留同一 `userData` 中的参数设置。导入图片、原图像素和字符结果只存在于当前运行期间，更新重启后不会恢复；请在确认更新前导出当前作品。

从 1.2.0 首次升级到 1.3.0 时，需要按 `F1` 手动检查更新并在浏览器打开官方 Release 页面下载，因为 1.2.0 没有内置替换逻辑。1.3.0 及之后版本支持本文描述的内置更新流程。源码开发和非 Windows/非便携运行时只能检测并打开官方下载页面，不会替换或删除源码、Electron 运行时或其他文件。

## 下载文件

本版本提供：

- `Glyph-Studio-1.3.0-Windows-x64.exe`
- `Glyph-Studio-1.3.0-Windows-x64.exe.sha256`

下载后可用 Windows PowerShell 验证哈希：

```powershell
Get-FileHash .\Glyph-Studio-1.3.0-Windows-x64.exe -Algorithm SHA256
```

便携版面向 Windows 10/11 x64，未配置代码签名；运行前请确认下载来源，并核对维护者提供的哈希和文件大小。
