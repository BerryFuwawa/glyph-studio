# 更新日志

本文件记录源码和构建行为，不代表某个版本已经在 GitHub 或其他渠道公开发布。

## 1.3.0 — 2026-10-03

### 自动检查与更新

- Windows x64 便携版每次启动自动读取 GitHub 最新稳定版本元数据；右下角显示“自动检查更新…”，“已是最新版”或“检查失败点击重试”。
- 检测到新版本时，右下角显示红点和“检测到更新，点击更新”。用户确认“更新并重启”后，界面会提示先导出当前作品，再下载官方 Windows x64 Release EXE 并显示进度，下载期间可以取消。
- 下载完成后同时核对发布的 SHA-256 摘要和文件大小。隐藏的 Windows helper 等待旧文件解锁、保留备份、替换为官方版本文件名并重启；只有新版本完成启动握手后才删除备份，失败时保留或恢复旧版本。
- 取消下载、只读目录、离线、下载不完整、缺少摘要或校验失败会显示中文错误并保留旧版本，不请求管理员权限。源码运行和非 Windows/非便携运行时只检测并打开官方下载页面，不替换或删除源码、Electron 运行时或其他文件。

### 网络、数据与迁移

- 图像解码、转换和导出继续在本机完成；启动检查只向 `api.github.com` 读取版本元数据，确认更新后才从 GitHub Release 或 `release-assets.githubusercontent.com` 下载官方资产，不发送图片、账号或其他应用数据。
- 更新保留同一 `userData` 中的参数设置；当前导入图片和字符结果不持久化，重启后不会恢复。
- 从 1.2.0 首次升级到 1.3.0 时仍需按 `F1` 手动检查并在浏览器下载，因为 1.2.0 没有内置替换逻辑；1.3.0 及之后版本支持内置流程。

## 1.2.0 — 2026-10-03

### 新增与调整

- “排版间距”新增“自动补正画面比例”复选框，默认开启；行间距和字符间距会参与物理字符网格测量，并按接近原图比例的方式重算行数。
- 行间距增大通常减少行数，字符间距增大通常增加行数；600 行和 180,000 个字符格的限制可能使实际列数减少。
- 自动补正开关与其他参数一样保存到本机，并支持撤销、重做和重置；旧版本保存的设置会迁移为开启状态。
- 修正单色配色选择器的居中显示。

### 间距与导出

- 关闭自动补正时保持固定转换网格，间距会像 1.1.1 一样拉伸画布。
- 画布预览以及 PNG、SVG、HTML 导出会保留物理行间距和字符间距。
- TXT、ANSI 和“复制字符”无法编码像素间距；自动补正开启时，间距导致的字符网格变化会反映在导出的文字中。

### 网络与隐私边界

- 图片解码、转换和导出继续在本机完成；不上传图片，不需要账号。
- 1.1.1 的手动更新检查行为保持不变：只有用户在帮助（`F1`）中主动检查更新时才访问 `api.github.com`，不会在启动时检查、自动下载或安装更新。

## 1.1.1 — 2026-10-03

### 新增

- 在帮助（`F1`）中加入“检查更新”，显示当前版本、检查中、最新版本和检查失败状态；失败时可重试。
- 发现新版本时显示可用版本；点击“前往下载”会在默认浏览器中打开官方 GitHub Release 页面。

### 网络与隐私边界

- 图片解码、转换和导出继续在本机完成；不上传图片，不需要账号。
- 只有用户主动检查更新时才访问 `api.github.com` 读取版本元数据；不会在启动时检查、自动下载或安装更新。主窗口会话的 HTTP、HTTPS 和 WebSocket 网络阻断保持不变。

## 1.1.0 — 2026-10-03

### 新增

- 新增“排版间距”侧栏：行间距可设为 0–24 px，字符间距可设为 0–12 px，两项默认均为 0。
- 画布预览以及 PNG、SVG、HTML 导出会跟随当前行间距和字符间距。
- 排版间距与其他转换参数一样持久化，并支持撤销、重做和重置。
- 在固定字符网格下，TXT、ANSI 和“复制字符”保持原字符字符串与换行不变，不携带像素间距；导出窗口会提示该行为。

### 已知范围

- 动图仍只转换第一帧；不提供视频、动画导出或批量处理。
- 输出仍受最长边采样、600 行和 180,000 字符格限制。
- 便携版仍未配置代码签名，Windows 可能显示 SmartScreen 警告。
- 跨设备查看 SVG/HTML/TXT/ANSI 时，字体和终端能力可能改变字形或颜色表现。

## 1.0.0 — 2026-10-02

### 新增

- Windows 10/11 x64 portable Electron 桌面应用，运行时使用 Electron `44.5.1`。
- 四种转换模式：经典 ASCII、盲文点阵、轮廓线稿和像素方块。
- 五种导出格式：TXT、PNG、SVG、HTML 和 ANSI。
- 支持 PNG、JPG/JPEG、WebP、BMP、GIF、AVIF，以及拖放、原生打开和剪贴板粘贴。
- 实时预览、参数撤销/重做、缩放、原图对照、五种单色配色和原图色输出。
- 本机离线处理；参数本地保存，导入图片和字符结果不写入历史文件。
- 输入大小与尺寸检查、超大图缩小、固定输出网格上限、HTML/SVG 转义和受限 IPC。

### 验证

- 源码开发环境按 Node.js `>=24` 配置，Node.js 24 已验证。
- `npm test`、渲染器冒烟、桌面 IPC/导出和浏览器渲染检查已覆盖核心转换与最终交互。
- `Glyph-Studio-1.0.0-Windows-x64.exe` 已完成本地 Windows x64 portable 启动和功能检查；是否分发由维护者另行决定。

### 已知范围

- 动图只转换第一帧；不提供视频、动画导出或批量处理。
- 输出受最长边采样、600 行和 180,000 字符格限制。
- 便携版未配置代码签名，Windows 可能显示 SmartScreen 警告。
- 跨设备查看 SVG/HTML/TXT/ANSI 时，字体和终端能力可能改变字形或颜色表现。
