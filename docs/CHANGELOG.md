# 更新日志

本文件记录源码和构建行为，不代表某个版本已经在 GitHub 或其他渠道公开发布。

## 1.0.0 — 2026-10-02

### 新增

- Windows 10/11 x64 portable Electron 桌面应用，运行时使用 Electron `44.5.1`。
- 四种转换模式：经典 ASCII、盲文点阵、轮廓线稿和像素方块。
- 五种导出格式：TXT、PNG、SVG、HTML 和 ANSI。
- 支持 PNG、JPG/JPEG、WebP、BMP、GIF、AVIF，以及拖放、原生打开和剪贴板粘贴。
- 实时预览、参数撤销/重做、缩放、原图对照、五种单色配色和原图色输出。
- 本机离线处理；参数本地保存，导入图片和字符结果不写入历史文件。
- 输入大小与尺寸检查、超大图缩小、固定输出网格上限、HTML/SVG 转义和受限 IPC。

### 验证

- 源码开发环境按 Node.js `>=24` 配置，Node.js 24 已验证。
- `npm test`、渲染器冒烟、桌面 IPC/导出和浏览器渲染检查已覆盖核心转换与最终交互。
- `Glyph-Studio-1.0.0-Windows-x64.exe` 已完成本地 Windows x64 portable 启动和功能检查；是否分发由维护者另行决定。

### 已知范围

- 动图只转换第一帧；不提供视频、动画导出或批量处理。
- 输出受最长边采样、600 行和 180,000 字符格限制。
- 便携版未配置代码签名，Windows 可能显示 SmartScreen 警告。
- 跨设备查看 SVG/HTML/TXT/ANSI 时，字体和终端能力可能改变字形或颜色表现。
