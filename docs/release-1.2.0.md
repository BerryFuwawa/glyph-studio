# 字相 · Glyph Studio 1.2.0

1.2.0 让排版间距参与画面比例补正，同时保留 1.1.1 引入的手动更新检查和本机隐私边界。

## 亮点

- “排版间距”新增“自动补正画面比例”复选框，默认开启。程序会把行间距和字符间距纳入物理字符网格测量，并按接近原图比例的方式重算行数。
- 行间距增大通常减少行数，字符间距增大通常增加行数；输出仍受最多 600 行和 180,000 个字符格的限制，达到限制时实际列数也可能减少。
- 关闭“自动补正画面比例”后保持固定转换网格，让间距像 1.1.1 一样拉伸画布。
- 自动补正开关与间距设置一起保存到本机，并支持撤销、重做和重置；从旧版本迁移的设置默认开启自动补正。
- 修正单色配色选择器的居中显示。

## 导出行为

画布预览以及 PNG、SVG、HTML 导出会保留物理行间距和字符间距。TXT、ANSI 和“复制字符”保存字符与换行，无法表达像素间距；启用自动补正时，间距导致的字符网格重算会反映在导出的文字行数或列宽中。

## 网络与隐私

图片解码、转换和导出仍在本机完成，不上传图片、不需要账号。只有用户在帮助（`F1`）中主动选择“检查更新”时，程序才会向 `api.github.com` 请求版本元数据；不会在启动时检查，也不会自动下载或安装更新。发现新版本后，点击“前往下载”会在默认浏览器打开官方 GitHub Release 页面。

## 下载文件

本版本提供：

- `Glyph-Studio-1.2.0-Windows-x64.exe`
- `Glyph-Studio-1.2.0-Windows-x64.exe.sha256`

下载后可用 Windows PowerShell 验证哈希：

```powershell
Get-FileHash .\Glyph-Studio-1.2.0-Windows-x64.exe -Algorithm SHA256
```

便携版面向 Windows 10/11 x64，未配置代码签名；运行前请确认下载来源，并在维护者提供哈希时自行核对。
