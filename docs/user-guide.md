# 字相用户指南

字相把照片、头像或插画变成由字符拼成的静态图。它适合做复古头像、社交分享图、文档或个人网站插图，也可以当作终端装饰。想让别人看到相同外观，导出 PNG；纯文本要用等宽字体查看或粘贴。

字相是“把画面变成字符”，不是 OCR。它不会读取截图里的正文，也不能把图片中的文字提取成可编辑内容；图片里的字只会作为明暗和轮廓参与转换。

## 开始前

当前版本是 1.3.0，便携版支持 Windows 10/11 x64。每次只处理一张静态图片；GIF 等动图只取第一帧，不会导出动画。支持 PNG、JPG/JPEG、WebP、BMP、GIF 和 AVIF。

图片解码、转换和导出都在本机完成，不上传图片，也不需要账号。启动时程序会联网检查版本，联网只用于更新检查或你确认后的更新下载。

## 三步完成一张字符画

### 1. 放入图片

把图片拖进窗口，或点击“打开图片”；也可以先复制图片，再按 `Ctrl+V` 或点击“粘贴图片”。导入后左侧会显示来源，右侧会实时显示原图和字符结果。

单个文件最大 50 MB，原图最多 4,000 万像素，任一边不超过 20,000 像素。为保持操作流畅，参与转换的图像会先在本机缩到最长边 1,600 像素以内。

### 2. 选择字符风格

| 模式 | 适合怎么用 |
| --- | --- |
| 经典 ASCII | 用疏密不同的字符表现明暗，适合大多数照片和头像。 |
| 盲文点阵 | 一个字符放入更多点，细节更密；查看时要用支持 Unicode 盲文的字体。 |
| 轮廓线稿 | 只保留物体边缘和方向线，适合轮廓清楚的照片或插画。 |
| 像素方块 | 用 `░▒▓█` 等方块表现明暗，适合复古颗粒感。 |

### 3. 调整并预览

先调“字符宽度”。宽度越小，画面越简洁；越大，细节越多，输出文件也会更大。可调范围是 40–280 列，预览会随设置更新。

“亮度”会把整张图一起调亮或调暗；画面太黑可调高，太亮可调低。“对比度”控制明暗差别。颜色可以选单色配色，也可以选择“原图色”。

“行间距”是在上下两行之间加空白，“字符间距”是在左右字符之间加空白。两项默认都是 0 px；PNG、SVG 和 HTML 会保留画布间距，TXT 和 ANSI 只保存字符及换行。

“自动补正画面比例”默认开启。它会把字符间距和行间距也算进去，重新安排字符行数，让结果尽量保持原图的宽高感觉。只想锁定字符网格时可以关闭；关闭后，增加间距会直接拉伸画布。

自动补正可能改变复制文本的行数或列宽，因为文本没有像素留白可以保存。需要保留当前预览外观时，使用 PNG；需要继续编辑字符时，使用 TXT 并选择等宽字体。

进阶调节里还有自动增强对比度、反转明暗、Gamma、抖动和阈值。遇到明暗不清、轮廓太弱时再尝试这些选项；不同模式显示的选项可能不同。

阈值只在盲文点阵和轮廓线稿中显示；抖动不适用于轮廓线稿和像素方块。ASCII 的自定义字符序列必须由单格字符组成，不能包含汉字、表情、组合字符或换行。

## 复制和导出

“复制字符”复制当前字符网格和换行。它不包含颜色或像素间距，粘贴到聊天、编辑器或终端时请使用等宽字体，例如 Cascadia Mono 或 Consolas。

点击“导出作品”后可以选择：

| 格式 | 适合用途 |
| --- | --- |
| PNG | 保留当前预览的外观、配色和排版间距，适合分享、文档和网站插图。 |
| TXT | 保存字符和换行，适合粘贴或继续编辑；不保存颜色和像素间距。 |
| SVG | 保存文字、颜色和排版间距，适合缩放和排版；不同设备的字体可能不同。 |
| HTML | 独立网页文件，浏览器可直接打开，保留文字、颜色和排版间距。 |
| ANSI | 适合支持 UTF-8 和真彩色的终端；不保存像素间距。 |

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 打开图片 | `Ctrl+O` |
| 粘贴图片 | `Ctrl+V` |
| 复制字符 | `Ctrl+C` |
| 导出作品 | `Ctrl+S` |
| 撤销 / 重做参数 | `Ctrl+Z` / `Ctrl+Y` |
| 适应窗口 | `Ctrl+0` |
| 临时查看原图 | 在画布区域按住空格 |
| 打开帮助 | `F1` |

## 数据、限制和更新

转换参数保存在本机，所以重新打开程序时会保留上次的调整；当前导入的图片和字符结果只在本次运行中使用，退出或更新重启后不会恢复。重新打开时会载入内置示例图片。

右下角会显示“自动检查更新…”。检查完成后会显示“已是最新版”或“检查失败点击重试”；发现新版本时，右下角出现红点和“检测到更新，点击更新”。检查失败时可点击状态重试。

点击更新后，程序先显示“更新并重启”的确认框。确认前请先导出当前作品，因为更新重启后不会恢复当前导入图片和字符结果。

确认后，官方 Windows x64 Release EXE 会下载到当前便携版所在目录，界面会显示进度并提供取消按钮。下载完成后会校验 SHA-256 和文件大小，再退出程序、替换旧版并启动新版。

如果取消下载，或下载、校验、替换失败，旧版会保留。新版启动失败时程序会恢复旧版；只有新版完成启动确认后才会清理旧版备份，清理失败时备份会继续保留。

更新会保留本机保存的转换参数，但不会恢复当前图片或字符结果。如果仍在使用 1.2.0，第一次升级请按 `F1` 手动检查并在浏览器打开官方 Release 页面下载；1.2.0 没有内置替换流程。

超长图片和输出会受文件、像素、行数和字符格上限影响；极端长宽比的图片可能自动减少实际列数。进阶控件的适用模式、字体显示和全部限制见[常见问题](faq.md)。
