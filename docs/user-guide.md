# 用户指南

## 1. 导入图片

打开便携版后，程序会先载入内置石膏像示例。你可以用以下任一方式替换它：

- 将一张图片拖到窗口；
- 点击“打开图片”并在 Windows 文件对话框中选择文件；
- 复制图片后按 `Ctrl+V`，或点击“粘贴图片”。

一次只处理一张图片。拖入多张图片时，程序打开第一张并提示其余文件未处理。支持 PNG、JPG/JPEG、WebP、BMP、GIF 和 AVIF。损坏、无法解码或超出限制的文件会显示错误提示，当前图片不会被静默替换。

程序在解码前检查文件大小和可识别的图像尺寸，随后把超大图片缩小到最长边 1,600 像素以内再交给转换核心。原始宽高仍显示在来源卡片中。GIF 或其他动图只取第一帧。

## 2. 选择转换模式

左侧模式卡片对应四种输出：

- **经典 ASCII**：用从稀疏到密集的字符表示明暗。字符序列默认是 ` .:-=+*#%@`，可在“自定义字符序列”中替换。
- **盲文点阵**：一个字符包含 2×4 个点，细节密度更高。查看和复制时请选择支持 Braille Unicode 的字体。
- **轮廓线稿**：检测方向边缘，输出 `/`、`\\`、`\|`、`-` 等方向字符，适合轮廓清晰的图像。
- **像素方块**：以空格和 `░▒▓█` 表达五级明暗，保留复古的颗粒感。

字符宽度可在 40–280 列之间调整。图片比例较长或较高时，程序会自动调整实际列数，以免输出超过 600 行或 180,000 个字符格；状态栏会提示实际结果尺寸。启用“自动补正画面比例”时，排版间距也会参与实际字符网格的计算。

## 3. 调整图像

“基础调整”中的控件会实时触发转换：

| 控件 | 作用 |
| --- | --- |
| 字符宽度 | 调整输出列数；宽度越大，细节越多，计算和导出内容也越大 |
| 行间距 | 在字符行之间增加 0–24 px 的额外留白；默认值为 0 |
| 字符间距 | 在相邻字符之间增加 0–12 px 的额外留白；默认值为 0 |
| 自动补正画面比例 | 默认开启；按字符网格的物理宽高重算行数，使结果接近原图比例；关闭后固定字符网格 |
| 亮度 | 在映射前整体提亮或压暗 |
| 对比度 | 拉开或压缩明暗差异 |
| 输出色彩 | 选择单色配色或按原图颜色着色 |
| 配色 | 单色模式下选择象牙白、琥珀、终端绿、冰蓝或白纸黑字 |

“排版间距”侧栏中的两项以像素为单位实时更新画布预览，0 表示保持默认排版。“自动补正画面比例”默认开启，行间距和字符间距会按实际字符格宽高重算行数：行间距增加通常减少行数，字符间距增加通常增加行数；触及网格限制时，实际列数也可能减少。关闭后保持固定转换网格，间距会像 1.1.1 一样拉伸画布。间距像素不会插入字符或换行，但开启自动补正时字符网格会重算，因此复制、TXT 和 ANSI 中的行数或列宽可能随设置变化。PNG、SVG 和 HTML 导出会跟随画布的行间距和字符间距。调整完成后，间距设置和自动补正开关与其他参数一样保存到本机，并进入参数历史，可用 `Ctrl+Z` / `Ctrl+Y` 撤销或重做；点击“重置”会恢复默认值 0 和开启状态。旧版本保存的参数会迁移为开启自动补正。

“高级调整”提供自动增强对比度、抖动补偿、反转明暗和 Gamma。阈值只在盲文点阵或轮廓线稿中显示；抖动在轮廓线稿和像素方块中不可用。参数历史支持 `Ctrl+Z` / `Ctrl+Y`，最多保留最近 60 个参数状态。

按住空格可临时查看原图，松开后返回之前的预览模式。`Ctrl+0` 让预览适应窗口；滚轮、缩放按钮和 `Ctrl+` / `Ctrl-` 可查看细节。

## 4. 复制和导出

“复制字符”复制的是带换行的字符字符串，而不是预览画布的截图。导出窗口提供：

- **TXT**：只含当前字符网格中的字符和换行，不含颜色或像素间距；
- **PNG**：保留当前预览的背景、配色、字体测量结果和排版间距；
- **SVG**：以文字元素保存，适合缩放和排版，并保留行间距和字符间距；
- **HTML**：独立文件，包含内联样式，浏览器离线即可打开，并保留行间距和字符间距；
- **ANSI**：每行带真彩色控制码，需在支持 UTF-8 和真彩色的终端中查看；字符字符串不包含像素间距，但可能反映自动补正重算后的字符网格。

“复制字符”与 TXT 导出的内容相同，只包含当前字符网格中的字符和换行，不会把排版间距编码进字符串；启用自动补正时，间距可能先改变网格，再改变复制出的行数或列宽。导出窗口会在 TXT 和 ANSI 选项的说明中提示这一点；需要保留当前预览的像素间距时，请选择 PNG、SVG 或 HTML。PNG 还可以从导出窗口复制到剪贴板。保存路径由 Windows 原生保存对话框决定，覆盖已有文件时会询问。若选择的文件名没有当前格式的扩展名，程序会自动追加正确扩展名。

## 5. 数据和隐私

图片解码、采样、字符转换和导出都在本机进行。程序没有账号、遥测或图片上传；主窗口会话的渲染器仍会拒绝普通 HTTP、HTTPS 和 WebSocket 请求。只有你主动选择“检查更新”时，程序才会向 `api.github.com` 请求版本元数据；不会在启动时自动检查，也不会自动下载或安装更新。转换参数（包括行间距、字符间距和自动补正画面比例）保存在 Electron 的本机存储中，导入图片、原图像素和字符结果只在当前运行期间保留。

退出后重新打开会恢复上次参数，并重新载入内置示例；不会恢复上次导入的图片或字符结果。

## 6. 检查更新

按 `F1` 打开帮助，选择“检查更新”。检查过程中会显示检查中状态；完成后会显示当前版本已经是最新版本，或显示可用的新版本。检查失败时会显示失败状态，并提供“重试”操作。

发现新版本后，点击“前往下载”会在默认浏览器中打开官方 GitHub Release 页面。该操作只打开下载页面，程序不会自动下载、安装或重启；应用启动时也不会主动检查更新。
