# 字相 · Glyph Studio

**把照片、头像或插画，变成一幅用文字拼出来的画。**

原图里的明暗和轮廓，会变成点号、符号、小点阵或方块。远看是一张图，近看是一行行字符。把图片拖进来，选一种风格，就能预览、复制或保存成品，不需要会写代码。

[下载 Windows 版](https://github.com/BerryFuwawa/glyph-studio/releases/latest) · [查看使用说明](docs/user-guide.md) · [遇到问题](docs/faq.md)

![字相：左边看原图，右边看用字符拼成的结果](docs/images/screenshot.png)

## 可以拿它做什么？

- **做复古风头像或分享图**：把自己的照片、宠物照、插画变成字符画，保存成 PNG，像普通图片一样上传或发给朋友。
- **给博客、个人主页或项目介绍配图**：做一张由文字和符号组成的插图，用 PNG 或 SVG 放进自己的页面或文档。
- **复制一幅“文字画”**：把结果复制出来，或保存为 TXT，在支持等宽字体的位置展示、编辑和使用。
- **装饰终端界面**：导出 ANSI 文件，在支持 UTF-8 和真彩色的终端里显示彩色字符画。文件怎么放进启动脚本，需要自己设置。
- **做一个能在浏览器打开的展示文件**：导出 HTML，得到一个不需要联网就能打开的字符画网页文件。

想直接把成品发给别人，**选 PNG 最省事**。把纯文字贴到聊天框或其他页面时，对方的字体、换行和空格处理可能让画面错位。

## 第一次使用，照着做就行

1. **下载并打开**：进入[下载页面](https://github.com/BerryFuwawa/glyph-studio/releases/latest)，下载 `.exe` 文件，双击运行。官方版本支持 Windows 10/11 的 64 位电脑，不需要另外安装 Node.js 或 Python。
2. **放入图片，选择风格**：把图片拖进窗口，或点击“打开图片”。软件自带一张示例图，也可以先拿它试试。点左边的风格卡片，就能看到变化。
3. **调整并保存**：调到喜欢的效果后，点击“导出作品”。分享图片选 PNG；需要文字就点击“复制字符”，或导出 TXT。

软件一次处理一张图片。先试一张主体清楚的头像、宠物照或插画，会更容易看出不同风格的区别。

## 四种风格长什么样？

| 界面里的名称 | 简单说，就是…… |
| --- | --- |
| 经典 ASCII | 用点号、冒号、`#`、`@` 等符号拼出明暗，像常见的文字画 |
| 盲文点阵 | 用细小的点拼图，通常能表现更多细节 |
| 轮廓线稿 | 主要表现边缘和线条，适合轮廓清晰的图片 |
| 像素方块 | 用深浅不同的小方块拼图，有颗粒感和复古感 |

可以切换“对照”“字符”“原图”来比较效果。按住空格临时看原图，松开后回到之前的预览。

## 怎样把效果调得更合适？

- **细节不够**：增加“字符宽度”。它表示一行放多少个字符，数值越大，通常能表现更多细节。
- **画面太暗或太灰**：试着调“亮度”和“对比度”，边调边看预览。
- **想换颜色**：选择单色配色，或选“原图色”，让字符跟着原图的颜色走。
- **字符挤得太紧**：增加“行间距”或“字符间距”。默认开启的“自动补正画面比例”会一起调整字符排列，尽量保持原图的长宽比例。
- **调过头了**：按 `Ctrl+Z` 撤销参数调整，或点“重置”重新开始。

行间距和字符间距会保留在 PNG、SVG 和 HTML 中。复制文字、TXT 和 ANSI 保存的是字符与换行，不能把像素间距一起带过去。

## 保存时，选哪个格式？

| 你想做的事 | 选这个 |
| --- | --- |
| 发给朋友、当头像、放进文档，尽量保留预览外观 | **PNG**：一张普通图片，保留配色和间距 |
| 复制成文字，继续编辑或放到文本里 | **TXT**：只有字符和换行，没有颜色 |
| 用文字图形进行缩放和排版 | **SVG**：用文字元素保存；换设备后字体可能有差异 |
| 用浏览器打开、展示字符画 | **HTML**：一个可以离线打开的网页文件 |
| 在支持颜色的终端里展示 | **ANSI**：带颜色控制码的文本，需要终端支持 |

文字画需要用**等宽字体**查看，也就是每个字符占一样宽的位置。字体不合适时，画面可能错位或显示成方框。跨设备分享时选 PNG，可以保留当前电脑上看到的外观。

## 图片会上传吗？关掉以后还能找回来吗？

**图片不会上传。**转换和导出都在你的电脑上完成，不需要注册账号；断网也能转换图片。

软件会记住你上次调整的参数，但**不会自动保存导入的图片或作品**。需要保留的结果，请在关闭软件或更新前点击“导出作品”保存。

启动时会联网检查有没有新版本，确认更新后才会下载安装包。更新请求不包含你的图片。

## 怎么更新？

每次启动，右下角会自动检查更新。有新版时，会出现红点和“检测到更新，点击更新”。没有新版时会显示“已是最新版”；检查失败可以点击重试。

点击提示并确认“更新并重启”后，软件会把新版下载到原程序所在文件夹，核对文件是否完整，再重启。新版成功启动后才删除旧版；下载或替换失败时保留或恢复旧版。下载时能看到进度，也可以取消。

**更新前先导出当前作品。**参数会保留，当前图片不会在重启后恢复。如果还在使用 1.2.0 或更早版本，请先从[下载页面](https://github.com/BerryFuwawa/glyph-studio/releases/latest)手动下载新版；1.3.0 起支持内置更新。

![右下角红点更新提示示例](docs/images/auto-update.png)

## 还有几个使用范围要知道

- 当前做的是静态字符画，不包含截图文字识别（OCR）、视频转换、动画导出或批量处理。GIF 等动图只转换第一帧。
- 支持 PNG、JPG/JPEG、WebP、BMP、GIF 和 AVIF。单个文件最大 50 MB；原图最多 4,000 万像素，最长边不超过 20,000 像素。
- 大图会先缩小后再转换。字符太多或图片比例特别长时，软件也会限制输出大小，方便预览和导出。
- Windows 可能提示“发布者未知”，因为当前程序没有代码签名。请确认下载来源；具体处理方法见[常见问题](docs/faq.md)。

更多操作见[用户指南](docs/user-guide.md)，版本变化见[更新日志](docs/CHANGELOG.md)。

## 源码开发

需要 Node.js `>=24` 和 npm，Electron 固定为 `44.5.1`。在仓库目录执行：

```powershell
npm ci
npm start
npm test
npm run build
```

依赖安装和 Electron 运行时准备可能需要网络。`npm ci` 成功不等于 Electron 已准备好；第一次运行或构建可能还需要下载运行时。源码运行可以检查更新并打开下载页面，只有打包后的 Windows x64 便携版支持就地替换更新。

构建产物在 `dist/`，1.3.0 的文件名为 `Glyph-Studio-1.3.0-Windows-x64.exe`。更完整的环境准备、验证命令和打包说明见[开发指南](docs/development.md)。

```text
src/                  应用源码、转换核心和内置素材
tests/                单元测试
scripts/              检查与图标生成脚本
docs/                 用户、开发、发布和许可文档
.github/              工作流、贡献指南和安全政策
package.json          依赖与构建配置
```
